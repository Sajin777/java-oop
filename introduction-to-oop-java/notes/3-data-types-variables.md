# Data Types and Variables

## Primitive types

| Type | Example |
|---|---|
| `byte` | `byte age = 20;` |
| `short` | `short year = 2026;` |
| `int` | `int marks = 95;` |
| `long` | `long population = 100000L;` |
| `float` | `float price = 12.5f;` |
| `double` | `double salary = 50000.50;` |
| `char` | `char grade = 'A';` |
| `boolean` | `boolean passed = true;` |

## Syntax

```java
dataType variableName = value;
```

Example:

```java
int age = 20;
String name = "Sajin";
```

## Type conversion

```java
int x = 10;
double y = x;       // widening

double a = 10.5;
int b = (int) a;    // narrowing
```
