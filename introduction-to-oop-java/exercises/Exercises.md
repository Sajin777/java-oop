# Exercises — Introduction to Java

## Beginner

1. Print your name, department and college.
2. Read two integers and display their sum, difference, product and quotient.
3. Find the largest of three numbers.
4. Check whether a number is even or odd.
5. Print numbers from 1 to 100.
6. Find the sum and average of an integer array.
7. Find the largest and smallest value in an array.
8. Count positive and negative values in an array.
9. Print a multiplication table.
10. Build a simple grade calculator.

## Challenge

Create a program that accepts 5 student marks, calculates total and average, and displays a grade.
