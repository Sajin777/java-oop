# Operators

## Arithmetic

`+  -  *  /  %`

```java
int a = 10;
int b = 3;

System.out.println(a + b);
System.out.println(a % b);
```

## Relational

`==  !=  >  <  >=  <=`

## Logical

`&&  ||  !`

## Assignment

`=  +=  -=  *=  /=  %=`

## Increment/decrement

`++  --`

## Ternary

```java
int marks = 75;
String result = marks >= 50 ? "Pass" : "Fail";
```
