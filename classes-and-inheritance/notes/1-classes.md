# Classes and Objects

## Syntax

```java
class Student {
    String name;

    void display() {
        System.out.println(name);
    }
}

Student s = new Student();
```

A class is a blueprint. An object is an instance.

## Example

```java
class Car {
    String model;

    void drive() {
        System.out.println(model + " is moving");
    }
}
```
