# Exercises — Classes and Inheritance

1. Create a `Student` class with private name, roll number and marks.
2. Add setters and getters.
3. Create a grade-calculation method.
4. Create `Employee` and `Manager` using inheritance.
5. Demonstrate constructor overloading.
6. Demonstrate method overloading using a `Calculator`.
7. Demonstrate overriding using `Animal`, `Dog` and `Cat`.
8. Demonstrate `super` to call a parent constructor.
9. Create an abstract `Shape` class with `Circle` and `Rectangle`.
10. Demonstrate dynamic method dispatch.
