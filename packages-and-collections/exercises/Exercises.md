# Exercises — Packages & Collections

1. Create your own package with a `Calculator` class.
2. Use `ArrayList` to store student names.
3. Remove duplicates using `HashSet`.
4. Store roll number and name using `HashMap`.
5. Sort a list of integers.
6. Use a `Deque` as a stack.
7. Use a `Queue` for customer service.
8. Build a small student record manager using collections.
