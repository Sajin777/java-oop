# Exercises — Interfaces, Exceptions & Strings

1. Create `Payment` with `CreditCard`, `UPI` and `Cash`.
2. Create `Camera` and `GPS` interfaces and implement both in `Smartphone`.
3. Handle division by zero.
4. Handle invalid array indexes.
5. Create a custom `InvalidMarksException`.
6. Count vowels in a String.
7. Reverse a String.
8. Check whether a String is a palindrome.
9. Count character frequency.
10. Build a menu-driven calculator with exception handling.
