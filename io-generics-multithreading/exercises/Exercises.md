# Exercises — I/O, Generics & Multithreading

1. Write and read a text file.
2. Count lines and words in a file.
3. Create a generic `Box<T>`.
4. Create a generic `Pair<K,V>`.
5. Create two threads by extending `Thread`.
6. Create two tasks using `Runnable`.
7. Demonstrate `join()`.
8. Create a synchronized counter.
